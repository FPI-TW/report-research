## 1. 產品脈絡與設計立場

### 1.1 產品是什麼

**廷豐智能研報**：券商研究報告平台。內部金融專業人員在此——

1. **檢索**：語意搜尋上萬篇券商研報（PDF），以市場／商品類型／標的／報告類型篩選。
2. **問答**：多輪 RAG 對話，回答附 `[n]` 引用徽章、可點開原始報告；可一鍵生成完整 PDF 深度研報。
3. **監控**：研報導入管線的即時儀表板（KPI、進度、速率、市場分佈）。

介面語言為**繁體中文**；使用者是每天長時間盯盤面的分析師與研究員，重效率、重密度、重可信感。

### 1.2 設計方向（已拍板，不可改）

> **精緻 SaaS 底 × 襯線編輯標題** — Linear/Notion 式安靜冷灰工作介面，
> 承載 FT 刊物感的襯線深金標題。

**簽名元素（signature）**：`襯線（Noto Serif TC）＋深金 #8a5a0f` 的內容標題系統，
以品牌字 glyph「**廷**」（襯線 800、深金）為識別錨點。全站唯一的「大膽」都花在這裡；
其餘一切（chrome、控制項、留白）保持安靜、克制、精確。

**核心組織原則（一句話記住整個系統）**：

> **襯線＝內容，無襯線＝工具。**
> 研報標題、頁區標題、問答回答的標題層級用襯線；
> 按鈕、輸入框、選單、標籤、表格等所有操作元素一律無襯線。

### 1.3 品牌淵源（從原版繼承什麼）

原版 vanilla 介面是 Apple/iOS 風（SF Pro、#f2f2f7 底、玻璃模糊側欄、圓角 16）。重設計**保留**：

- 品牌金雙色：主金 `#ae7415`（取自公司 logo）、深金 `#8a5a0f`。
- 市場／商品類型的**語意色系統**（iOS 色板，見 §4）——這是使用者已建立的認知，不得金色化。
- 全部繁中文案與資訊架構（欄位、篩選維度、流程）。
- 動效時長／緩動 token 與 reduced-motion 歸零機制。

**捨棄**：玻璃模糊、漸層背景、iOS 圓角 16、296px 寬側欄、emoji 空狀態。

## 2. 設計 Token

### 2.1 色彩 — 介面基調

| Token | 值 | 用途 |
|---|---|---|
| `--tf-canvas` | `#f6f7f9` | 頁面畫布底（冷灰，非暖灰） |
| `--tf-surface` | `#ffffff` | 卡片、面板、輸入框、導覽軌 |
| `--tf-border` | `#e4e7ec` | 標準邊框 |
| `--tf-border-weak` | `#f2f4f7` | 弱邊框、hover 底、次要標籤底、分隔 |
| `--tf-text-1` | `#101828` | 主標題 |
| `--tf-text-2` | `#344054` | 內文 |
| `--tf-text-3` | `#667085` | 次要文字（meta、導覽 idle） |
| `--tf-text-4` | `#98a2b3` | 弱化文字（count、placeholder） |

### 2.2 色彩 — 品牌金

| Token | 值 | 用途 |
|---|---|---|
| `--tf-gold-text` | `#8a5a0f` | **金色文字唯一合法色**（白底對比 ≈5.4:1，過 AA）；主按鈕底、選中態底、score 填充 |
| 品牌主金 | `#ae7415` | **只准用於大字（≥18.66px bold）與裝飾底色**，絕不做小字文字色 |
| `--tf-gold-tint` | `#faf3e3` | 金色淡底（active 膠囊、回顯 chip、導覽 active 底） |
| `--tf-on-gold` | `#ffffff` | 深金底上的主文字 |
| `--tf-on-gold-muted` | `rgba(255,255,255,.75)` | 深金底上的次要文字（篇數 count 等） |

金色 10 階色票（衍生自品牌金，Mantine tuple；index 7＝主色、index 9＝深金）：

```
#fbf3e3  #f3e4c6  #e7c98c  #dbaf52  #d09a26
#c98e10  #c58808  #ae7415  #9c6710  #8a5a0f
```

**對比硬規則**：任何金色文字一律 `#8a5a0f`。`#ae7415` 出現在文字上時必須 ≥18.66px 粗體。

### 2.3 字型

| 角色 | 字族 | 權重 | 用途 |
|---|---|---|---|
| 襯線（display） | `'Noto Serif TC', Georgia, 'Times New Roman', serif` | 600 / 700（品牌 glyph 800） | 品牌字、頁區標題、結果卡標題、問答回答 markdown 標題、研報面板標題、分組標頭 |
| 無襯線（UI/body） | `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Segoe UI", "PingFang TC", "Microsoft JhengHei", system-ui, sans-serif` | 400–700 | 其餘一切：按鈕、輸入框、選單、標籤、表格、meta、內文 |

- Noto Serif TC 經 Google Fonts CDN 載入（`display=swap`，unicode-range 自動切片）；CDN 不通時退系統襯線，**不得阻塞渲染**。
- **數字**：統計、表格、監控 KPI 一律 `font-variant-numeric: tabular-nums`。

### 2.4 字級層級（px）

| 層級 | 大小 / 行高 | 字族 | 範例 |
|---|---|---|---|
| 品牌 glyph | 22 / 1 | 襯線 800 | 左軌「廷」 |
| 頁標題 | Mantine `Title order={2}`（≈26） | 襯線 700 | 「研報導入監控」 |
| 區塊標題 | `Title order={3} size="h5"`（≈16） | 襯線 700 | 監控面板標題 |
| KPI 數字 | 26 / 1.3 | 無襯線 700 + tabular | 監控 KPI |
| 結果卡標題 | 14.5 / 1.45 | 襯線 700，色 `--tf-text-1` | 研報檔名 |
| 分組標頭 | 15 | 襯線 700 | 「2026 年 6 月（12 篇）」 |
| 內文 | 14–15 / 1.5–1.7 | 無襯線 | 摘要、問答內文（問答 1.7） |
| meta / 次要 | 12–12.5 | 無襯線，色 `--tf-text-3` | 來源 · 日期 · 類型 |
| 標籤 / 徽章 | 11–13 | 無襯線 600 | 膠囊、chip、cite |

### 2.5 圓角

| 半徑 | 用途 |
|---|---|
| `12px` | 卡片、面板、輸入框、modal（Mantine Card/Paper 預設；取代原版 16） |
| `10px` | 導覽 active 膠囊、segmented 容器 |
| `999px`（full） | 所有膠囊：篩選 chip、市場徽章、回顯 chip、主／次按鈕、cite 徽章 |
| `md`（8px） | Mantine defaultRadius（一般小控制項） |

### 2.6 陰影

| Token | 值 | 用途 |
|---|---|---|
| 卡片淡影（`xs`） | `0 1px 3px rgba(16,24,40,.06)` | 所有卡片預設，搭 `1px solid --tf-border` |
| segmented active | `0 1px 3px rgba(16,24,40,.12)` | 檢視切換選中鈕 |
| 浮動輸入卡 | 較深一階（Mantine `sm`/`md`） | 問答 composer |

原則：**邊框為主、陰影為輔**。原版的大範圍柔影（`0 8px 24px`）不再使用。

### 2.7 動效

| Token | 值 |
|---|---|
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` |
| `--dur-1/2/3` | `120ms / 180ms / 240ms` |
| `--dur-4` | `340ms`（面板平移、滑塊） |

`prefers-reduced-motion: reduce` 時全部時長歸零。動效只用於：hover 抬升、面板進出場、進度條。不做裝飾性動畫。

| 卡片兩欄斷點 | `64em`：結果卡 `1fr 1fr`，以下一欄 |

## 5. 元件規格

### 5.1 全站導覽

**桌機左軌（AppRail，60px 白底）**，由上至下：

- 品牌 glyph「廷」：襯線 800 / 22px / `--tf-gold-text`，連到檢索頁。
- 三導覽項（直向排列）：圖示 20 + 10px label，`gap 3px`、`padding 8px 9px`、圓角 10、`min-width 46px`。
  - idle：`--tf-text-3`；hover：底 `--tf-border-weak`；
  - **active：底 `--tf-gold-tint`、字 `--tf-gold-text`、700**（金底膠囊）＋ `aria-current`。
- 底部：頭像鈕（30px 圓）→ Popover（帳號名＋登出）。

**手機底部分頁列（56px + safe-area，白底）**：四格等寬——檢索／問答／監控／帳號。
圖示與 label 同左軌；**active 只變色**（字 `--tf-gold-text` 700，無底色膠囊）。帳號格整格可點（觸控目標）。

### 5.2 卡片（Card / Paper）

`圓角 12 + 1px solid --tf-border + 陰影 0 1px 3px rgba(16,24,40,.06) + 白底`。
hover（可點卡片）：邊框轉 `--tf-gold-text`。focus-visible：`outline 2px solid --tf-gold-text, offset 2px`。

### 5.3 膠囊與標籤

| 元件 | 樣式 |
|---|---|
| 篩選 chip（ChipButton） | `padding 4px 12px`、圓角 999、13px；idle：白底＋`--tf-border` 框＋`--tf-text-2` 字（市場 chip 帶 8px 語意色圓點）；**active：`--tf-gold-text` 底＋`--tf-on-gold` 字**，count 用 `--tf-on-gold-muted` 11px |
| 回顯 chip（ActiveChip，可刪除） | `--tf-gold-tint` 底、`--tf-gold-text` 字、圓角 999、12px/600、`padding 2px 6px 2px 10px`、右側 × 鈕 |
| 市場徽章 | 市場色底、白字、圓角 999、`padding 1px 8px`、12px/600 |
| 次要標籤（商品類型） | `--tf-border-weak` 底、無框、圓角 999、11px |
| 引用徽章 `[n]` | 金色膠囊（`--tf-gold-tint` 底＋`--tf-gold-text` 字）、11.5px、可點 |
| `最新` 徽章 | 綠框描邊膠囊（框 `#34c759`／字 `#248a3d`） |
| `網路` 徽章 | amber（`#ff9f0a`）框描邊膠囊 |

### 5.4 按鈕

| 類型 | 樣式 |
|---|---|
| 主按鈕 | `--tf-gold-text` 底、白字、圓角 999、600、`padding 7px 22px`、無框（例：「瀏覽全部報告」「登入」） |
| 次按鈕 | 白底、`1px --tf-border` 框、圓角 999、金字 `--tf-gold-text` 600（例：「載入更多（還有 N 篇）」） |
| 工具鈕 | Mantine `variant="default" size="compact-sm" radius="xl"`（例：「更多篩選」，右側掛進階條件數的金色圓 Badge） |
| 送出鈕（問答） | 深金圓形 40px、白色上箭頭圖示 |

### 5.5 輸入框

- 搜尋列：置中限寬 560px、`size md`、圓角 12、左側 `IconSearch 18`、白底、`--tf-border` 框；focus：金色 ring。placeholder：`搜尋主題、公司、事件…`。
- 問答 composer：底部浮動白卡（圓角 12–16、陰影一階深）、textarea 自動增高、右下深金圓形送出鈕。placeholder：`輸入你的問題…`。
- focus ring 全站統一：`outline: 2px solid` 金、`offset 2px`。

### 5.6 檢視切換（segmented）

容器：`--tf-border-weak` 底、圓角 10、`padding 3px`；選項鈕 `padding 6px 14px`；
active：白底＋`0 1px 3px rgba(16,24,40,.12)` 陰影＋`--tf-text-1` 600。選項：卡片／表格。

### 5.7 載入 / 空 / 錯誤態

- **Skeleton 骨架屏**（取代單一 spinner）：4 張假卡（`padding 14px 16px`、圓角 12），64em 起兩欄。
- **空狀態**：襯線標題 700/16px（例：`找不到「查詢」的相關研報`）＋一句補救文案＋金色主按鈕（`清除篩選再試`／`瀏覽全部報告`）。無 emoji、無插圖。
- **錯誤態**：同結構，文案直說發生什麼與怎麼辦（例：`載入失敗，請稍後再試。`＋`重試` 鈕）。

### 5.8 進度與數據

- 進度條：高 9px、圓角 full、軌道灰、填充**金色**；不定式＝34% 寬滑塊來回；閒置＝灰。
- KPI tile：Card 預設＋label 12px `--tf-text-3`＋數字 26px/700/tabular＋後綴小字。
- 速率行：`速率 X.X 篇/分 · 預估剩餘 ~N 分`（12.5px 次要色）。

### 5.9 Modal

圓角 12、標準卡片語言。詳情 modal：標題（襯線）＋meta 行（市場徽章 · 來源 · 日期 · 類型）＋摘要區＋PDF iframe＋底列動作（`在新分頁開啟`／`下載原始檔`）。

## 7. 文案語調

- **繁體中文、句式直接**：控制項寫明動作結果（`載入更多（還有 N 篇）`、`清除篩選 · 2`、`下載 PDF`），不用「提交」「確定」這類含糊詞。
- **錯誤態講事實＋出路**：`報告載入失敗，請稍後再試或重新整理頁面。`；不道歉、不賣萌。
- **空狀態是行動邀請**：`找不到「查詢」的相關研報，換個說法或關鍵字試試`＋補救按鈕。
- **數據標註慣例**：`·` 圓點分隔 meta（`來源 · 日期 · 類型`）；`——`不用；千分位 `1,234`；日期 `YYYY/MM/DD`。
- 不用 emoji、不用驚嘆號、不用行銷語。

## 8. 無障礙硬規則（不可退步）

1. 文字對比一律 WCAG AA——金色文字必為 `#8a5a0f`。
2. 全站鍵盤焦點環：`outline 2px solid` 金＋`offset 2px`，永不移除。
3. 導覽 active 帶 `aria-current`；手機底欄項與帳號格觸控目標 ≥44px。
4. `prefers-reduced-motion` 時所有動效時長歸零。
5. 每頁唯一 h1（視覺隱藏的「廷豐智能研報」），標題梯級不跳號；導覽 landmark 不重複。
6. 篩選 chip 用 `aria-pressed`；Popover 觸發鈕帶 `aria-expanded`；表格排序帶 `aria-sort`。

## 9. Do / Don't

| Do | Don't |
|---|---|
| 襯線只給內容標題（研報標題、頁區標題、markdown 標題） | 襯線用在按鈕、輸入框、選單、表格、meta |
| 金色文字一律 `#8a5a0f` | `#ae7415` 做小字、或把金色當背景大面積鋪 |
| 市場／商品語意色照 §4 使用 | 把市場徽章金色化、自創語意色 |
| 邊框＋淡影的卡片 | 無框大柔影（舊 iOS 風）、玻璃模糊、漸層背景 |
| 膠囊（圓角 999）做標籤與按鈕 | 混用 4px 小圓角標籤（舊版樣式） |
| 數字 tabular-nums | 比例數字跳動 |
| Tabler 線性圖示 20/1.8 | emoji、實心雜牌圖示 |
| 空/錯態＝文字＋金色補救按鈕 | 插圖、emoji、無出路的死路訊息 |
| 平色畫布 `#f6f7f9` | 背景漸層 |
