# 券商觀點雷達行動版排版修正設計

## 背景

Playwright 實際渲染稽核顯示，桌面版的市場共識點圖與表格模式可正常操作；行動版切換成表格後，`620px` 的表格放在約 `356px` 的捲動容器中，使用者必須水平滑動，且捲動頁面時欄位標題可能進入固定頁首下方。行動版點圖按鈕的命中區為 `30 × 30px`，也小於本專案一般觸控控制項採用的 `44px` 慣例。Console 另有 `/favicon.ico` 404。

## 目標

- 桌面版維持高密度表格與點圖，不降低資訊密度。
- 行動版切換檢視時使用單欄券商卡片，不要求水平滑動。
- 行動版點圖提供至少 `44 × 44px` 的觸控命中區，視覺圓點尺寸保持不變。
- 清除 favicon 404，不引入外部資產依賴。
- 保留現有資料範圍、EPS 口徑、券商選取與鍵盤操作語意。

## 方案比較

### 方案 A：桌面表格、行動卡片（採用）

同一份券商資料在桌面渲染表格、行動版渲染卡片。卡片顯示券商、目標價、EPS、報告日期與資料新鮮度，並保留選取操作。

- 優點：不需要水平滑動；所有欄位標籤保持可見；可沿用專案既有券商卡片語言。
- 代價：同一資料有兩份呈現 DOM，需要測試確保內容與選取行為一致。

### 方案 B：保留行動版橫向表格

增加固定首欄、表頭 offset、滑動提示與右側漸層。

- 優點：與桌面完全一致。
- 代價：手機仍需要橫向捲動；固定欄與 sticky 表頭較容易再次發生層級或裁切問題。

### 方案 C：手機停用表格切換

在行動版只提供點圖，不顯示表格切換。

- 優點：實作最少。
- 代價：拿掉使用者已能使用的資料檢視方式，且點圖不適合快速讀取精確日期與數值。

## 元件設計

### 市場共識表格／卡片

`ConsensusSummary` 繼續以 `tableView` 控制「圖表／資料檢視」。資料檢視內同時提供桌面表格與行動卡片，由 CSS 媒體查詢控制顯示：

- `> 720px`：顯示既有表格。
- `<= 720px`：隱藏表格，顯示券商卡片清單。

每張卡片包含：

- 券商名稱，作為可選取按鈕。
- 目標價，以及幣別不符時的排除註記。
- EPS，以及口徑不符時的既有 `epsExclusionNote`。
- 報告日期。
- 資料新鮮度文字。

卡片按鈕使用 `aria-pressed` 表達選取狀態，並與桌面表格共用 `onSelect`，不建立第二份選取狀態。

### 點圖觸控範圍

`.mark` 維持 `11px`，只在 `max-width: 720px` 將 `.dot` 的寬高改為 `44px`，並同步把點圖列高與軌道高度調整為 `44px`，避免相鄰命中區重疊。桌面仍維持 `30px`。

### Favicon

新增本機 SVG favicon，並在 `frontend/index.html` 明確引用 `/app/favicon.svg`。圖示使用簡單文字／幾何標記，不載入第三方資產。

## 錯誤與空狀態

- 券商清單為空時，沿用現有「此範圍內沒有券商資料」文案。
- 缺少目標價或 EPS 時沿用 `NOT_PROVIDED`。
- 幣別與 EPS 口徑不相容時，卡片與表格必須逐字共用現有註記函式，避免兩種檢視說法分歧。

## 測試與驗證

1. 先新增會失敗的元件測試，證明行動卡片存在、欄位完整且能選取券商。
2. 新增 CSS 契約測試，要求行動版隱藏表格、顯示卡片，並要求點圖在行動版為 `44px`。
3. 實作最小修改後，執行 Radar 窄測試、完整前端測試、typecheck、lint 與 Vite build。
4. 重新建置 `frontend/dist`。
5. 使用隔離 Playwright 系統 Chrome 驗證：桌面表格仍可用；390px 行動版改為卡片、無水平溢位；圖表命中區為 `44 × 44px`；console 無 favicon 404。

## 非目標

- 不修改後端 API、資料 schema 或共識計算。
- 不重新設計桌面點圖或券商詳情面板。
- 不改變時間窗控制；現有 `radiogroup`／`radio` 與 `aria-checked` 已符合需求。
- 不在本次調整整個固定頁首架構。
